Quick answers
What happens after checkout?
You'll be sent to a secure medical questionnaire (~5 minutes). A Florida-licensed physician reads your case and either approves, modifies, or declines your prescription. Your card is authorized at checkout but not charged in full until provider approval.
What if I'm not approved?
If a provider determines this protocol isn't appropriate for you, you'll receive a written explanation and your card is automatically released — there is no charge for a declined case. In some cases the provider may suggest an alternative.
When does medication ship?
Generic prescriptions typically ship within 3–5 business days of provider approval; compounded protocols 5–7. All shipments are unbranded with tracking, signature on request.

Notes · WordPress + WooCommerce + Prescribery What's native, what's custom, what to defer

Built on WooCommerce + Prescribery, without looking like it.

Cart, checkout, and post-purchase handoff use native WC primitives plus a small set of integration hooks. Every piece of the clinical workflow is delegated to Prescribery — Adonis owns the experience, not the prescribing system.

Cart page WooCommerce native

  • Built on the WC Cart block — line items, totals, coupon code all native
  • Subscription toggle is a per-line variation switch (WooCommerce Subscriptions plugin)
  • "Save 33%" comparison computed server-side from $one_time vs $subscription_price — never hard-coded
  • Estimated tax = "Calculated at checkout" until ZIP is known (FL = 6% state + 1% Miami-Dade county)
  • Right-rail next-steps strip is a theme partial, not an order detail — same on every cart

Subscription control WC Subscriptions

  • Bi-monthly = billing_period: month + billing_interval: 2
  • Toggle persists via cart_item_data['_adonis_cadence']
  • Pause / cancel / dose-change exposed in member portal — no retention pitch, single click
  • Copy is fixed per brand brief: "Subscription is optional. Most members choose bi-monthly delivery to stay consistent and avoid refill gaps."

Checkout page WC + Stripe + custom blocks

  • Use WC Checkout block as the base, restyled via this CSS
  • Step bar is a custom block above the checkout block
  • Sticky right-rail summary is custom — uses woocommerce_review_order_before_cart_contents hook
  • Stripe in authorize-only mode: capture_method: manual on Payment Intent
  • Payment is captured via API webhook from Prescribery on provider approval

Form fields WC + ACF

  • Standard fields use WC default — billing_email, billing_first_name, etc.
  • Date of birth = custom field _adonis_dob, required, validated 18+
  • State dropdown filtered server-side to enabled states (FL only at launch)
  • Telehealth consent checkbox required, logged to order meta with timestamp + IP
  • HSA/FSA = Stripe payment method type — no separate processor

Prescribery handoff API + redirect

  • WC thankyou page = our handoff screen, not a generic receipt
  • On woocommerce_thankyou hook: POST order to Prescribery /cases
  • Prescribery returns questionnaire_url + case_id
  • "Continue to questionnaire" CTA links to that URL — opens Prescribery's flow in same tab or embedded iframe
  • Adonis stores case_id on order, polls Prescribery webhook for approval / decline / modification

Order lifecycle WC statuses

  • Checkout complete → status on-hold (not processing)
  • Payment Intent requires_capture — money authorized, not charged
  • Prescribery webhook case.approved → capture Payment Intent → status processing → pharmacy fulfillment
  • Webhook case.declined → cancel Payment Intent → status refunded → email user
  • Webhook case.modified → recalc total → re-authorize → email user for confirmation

Compliance copy do-not list

  • Never use: "guaranteed approval", "instant prescription", "no doctor needed", "cure ED", "cure hair loss", "results guaranteed"
  • Always pair Rx CTAs with provider-review reassurance — same line, same screen
  • Disclaimer: "Prescriptions are issued only when medically appropriate after review by a licensed provider. Results vary."
  • State licensure & 503A disclosure required in checkout footer + thank-you page
  • HIPAA + BAA-coverage badging on every checkout chrome (notice strip + handoff card)

Mobile checkout sticky pattern

  • Order summary collapses to a single line at top + sticky bottom CTA bar
  • Sticky bar has three things only: total, primary CTA, trust microcopy
  • Trust line near payment button is required by brief — "Card authorized · charged on provider approval · Stripe"
  • Pay-method radio collapses to compact 3-up grid; card cluster fields stack 1-up
  • No distractions in mobile checkout — no testimonials, no badges row, no upsells

Thank-you screen handoff, not receipt

  • Replaces WC default thank-you template via woocommerce_thankyou.php override
  • Headline: "Your online visit has started." — never "Order placed" / "Thanks for your purchase"
  • Three explicit next-step rows with timing — questionnaire, review, ship
  • Primary CTA links directly to Prescribery questionnaire URL (deep link with case_id)
  • Order reference shown for support, but it's not the focus

Do-not-build list defer to Prescribery

  • No custom medical questionnaire — embed Prescribery's
  • No custom provider dashboard — Prescribery owns the clinician UI
  • No custom Rx record / dispense log — Prescribery + pharmacy partner own the medical record
  • No custom video-visit tooling for Precision tier — Prescribery integrates with telehealth provider
  • Adonis owns: marketing site, product pages, cart, checkout, thank-you, member portal, subscription billing

Reusable components theme partials

  • parts/notice-strip.php — top compliance bar, used on cart + checkout + thank-you
  • parts/step-bar.php — 4-step progress, conditional class per current page
  • parts/handoff-card.php — green-accent Prescribery handoff explanation
  • parts/next-steps.php — 4-row "after this" strip with timing stamps
  • parts/reassure.php — single line provider-review reassurance, two variants (bronze, sec-green)

Design tokens shared

  • Inherits Adonis design system v4.5: graphite + warm ivory + bronze
  • Secondary green --sec: #2E4338 reserved for clinical reassurance + Prescribery handoff cards
  • Single CTA color across whole flow — bronze gold --acc: #C9A35E
  • Italic Fraunces emphasis only — never as body copy
  • Forms use a single border treatment — no boxed inputs, no lifted cards in form fields
